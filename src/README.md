# Python Source Code

This directory contains the Python implementation of the CAN-Based EV Battery Digital Twin.

## Planned Modules

- `can_simulator.py` — CAN message encoding and virtual transmission
- `can_decoder.py` — DBC-based CAN signal decoding
- `battery_model.py` — Battery state tracking
- `database.py` — SQLite battery data storage
- `fault_detection.py` — Battery fault detection
- `dashboard.py` — Streamlit battery monitoring dashboard
- `main.py` — Main application entry point

Modules will be added and tested incrementally.

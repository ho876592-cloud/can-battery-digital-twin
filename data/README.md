# Battery Simulation Data

This folder contains battery measurements generated using the MATLAB/Simulink battery model.

The dataset includes:
- Simulation time (s)
- Battery current (A)
- Battery terminal voltage (V)
- State of Charge (%)
- Battery temperature (°C)

The initial dataset contains 601 simulated samples at a 1-second sampling interval.

All measurements are simulated and intended for educational development and testing.
